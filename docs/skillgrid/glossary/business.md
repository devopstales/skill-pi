# Business Glossary

| Term | Definition |
|---|---|
| **isolated install** | skill-pi runs pi with its own global config (`~/.skill-pi/agent`), sessions, and credentials, never reading or writing the stock `~/.pi/agent`. |
| **bundled extensions** | pi extensions shipped inside the skill-pi npm package and loaded on every launch. |
| **user extensions** | pi extensions a user drops into `~/.skill-pi/agent/extensions/` for all projects. |
