# Triage Labels

| Label | Meaning |
|---|---|
| `needs-triage` | Unread, unclassified |
| `needs-info` | Blocked on reporter/more detail |
| `ready-for-agent` | Scoped, implementable by an agent |
| `ready-for-human` | Requires human judgment |
| `wontfix` | Accepted as-is / deferred indefinitely |
