# Issue Tracker

**Tracker:** GitHub Issues (`gh` CLI)
**Repo:** `devopstales/skill-pi` (`git@github.com:devopstales/skill-pi.git`)

## Conventions

- One issue per SDD change (`NNN-<slug>` title prefix).
- Labels per `triage-labels.md`.
- Issue body mirrors `change.md` Goal + Definition of Done.
- Link issue from `change.md` header `Ticket:` field.

## Workflow

- `issue-creation` maps tasks to issues (duplicate search first).
- On archive: link the merge/PR in the issue.
