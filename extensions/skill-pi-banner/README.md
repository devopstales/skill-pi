# @devopstales/pi-skill-pi-banner

skill-pi branded banner for pi: shows the skill-pi logo, version, and agent dir on session start.

## Install

```bash
pi install npm:@devopstales/pi-skill-pi-banner
```

Or bundled with skill-pi (auto-discovered from `extensions/skill-pi-banner/index.ts`).

## Development

```bash
npm install
npm test          # vitest
npm run check     # tsc --noEmit
```
